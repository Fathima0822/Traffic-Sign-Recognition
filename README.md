 # Traffic Sign Recognition Using Deep Learning & CNN

An academic team capstone project evaluating multi-class road traffic sign classification using Convolutional Neural Networks (CNN) with Python, TensorFlow, and Keras.

---

## 📌 Project Overview

This project explores the application of a Convolutional Neural Network (CNN) pipeline to categorize road sign images using the German Traffic Sign Recognition Benchmark (GTSRB) dataset.

### Key Objectives
- Organize and preprocess image data across 43 traffic sign categories.
- Implement a standard sequential CNN architecture.
- Train and evaluate the model to observe classification accuracy.
- Test predictions on sample road signs.

---

## 🛠️ Tech Stack & Tools

- **Language:** Python
- **Libraries:** TensorFlow, Keras, NumPy, Pandas, Matplotlib
- **Dataset:** German Traffic Sign Recognition Benchmark (GTSRB)

---

## 📂 Dataset Details

- **Classes:** 43 traffic sign types (Speed limits, cautionary signs, mandatory signs).
- **Preprocessing:** Resizing images to a uniform dimension, normalizing pixel values, and one-hot encoding labels.

---

## 🏗️ Architecture Summary

- **Convolutional Layers:** Feature extraction from traffic sign images.
- **Activation:** ReLU for non-linear feature mapping.
- **Pooling Layers:** Spatial downsampling to reduce feature dimensions.
- **Dropout:** Mitigating overfitting during model training.
- **Dense & Softmax Layer:** Multi-class probability output for 43 categories.

---

## 👥 Project Scope & Attribution

- **Project Type:** Academic Capstone (Team Project)
- **Role Focus:** Dataset organization, running model execution pipelines, and recording test accuracy.
